Trình duyệt Linux siêu nhẹ, mượt mà và tôn trọng riêng tư. The Ultra-Lean, Memory-Safe Browser For Linux Workstations.

Tách biệt hoàn toàn giao diện Rust WASM với khung nhìn WebKitGTK 4.1 gốc của Linux. Nói KHÔNG với việc ngốn cả gigabyte RAM như Chromium: máy chạy êm ru với chỉ ~118MB RAM, tích hợp sẵn nhân chặn quảng cáo 300k rules của Brave, tải đa luồng chuẩn IDM và két mật khẩu Argon2id. Engineered by decoupling a reactive Rust WebAssembly UI from native Linux WebKitGTK 4.1 viewports. Vibird eliminates Chromium's 800MB RAM overhead: baseline ~118MB memory footprint, 300k+ Brave filter rules, IDM-style multithread downloader, and an Argon2id Vault.

Không kéo theo Node.js, không cồng kềnh như Chromium, không ví tiền ảo hay quảng cáo rác. Zero bundled Node.js runtimes, zero V8 bloatware, and no commercial crypto ecosystem upsells.

Lõi lọc Vibird Shield (Hơn 300.000 Rules) Vibird Shield Core (300k+ Rules)

Chạy trên một thread hệ điều hành độc lập với thuật toán tra cứu Bloom Filter siêu tốc. Tích hợp sẵn EasyList, EasyPrivacy và Fanboy Annoyance. Can thiệp sâu từ prototype của DOM để chặn đứng mã theo dõi trước khi trình duyệt kịp gửi request ra ngoài và tự động tắt sạch các banner Cookie/GDPR phiền toái. Runs on an isolated OS worker thread hosting Brave Software's official engine. Precompiled with EasyList, EasyPrivacy, and Fanboy's Annoyance. Deep DOM prototype hooks intercept trackers before raw requests dispatch, automatically defusing cookie consent dialogs.

adblock-rust • Tokenized Trie

Tải file đa luồng xé băng thông như IDM IDM-Style Chunked Downloader

Tự động bắt HTTP Range, chia nhỏ file tải đồng thời từ 4 đến 16 luồng TCP độc lập. Tốc độ tải vượt trội và tự động bắt link tải (Download Sniffer) khi click vào file nén, file cài đặt. Forks payloads across 4 to 16 concurrent TCP threads via HTTP Range headers. Maximizes line throughput with sanitized directory sink writes.

Multi-Threaded • Tokio Async

Ru ngủ tab thông minh (Giải phóng RAM) Smart Tab Memory Snoozer

Tab nền không bấm tới quá 10 phút sẽ tự động được huỷ bỏ hoàn toàn Webview, trả lại 100% RAM và GPU cho máy tính để bạn làm việc với IDE, Docker. Bấm lại tab là mở lại ngay lập tức. Background tabs inactive for >10 minutes have their native WebKit viewports cleanly destroyed, returning 100% of DOM and GPU memory to the OS.

Zero RAM Leak • Auto-Evict

Két mật khẩu Vibird Vault (Argon2id + AES-256) Vibird Vault (Argon2id + AES-256-GCM)

Ứng dụng mô hình mã hoá Envelope chống bẻ khoá bằng dàn GPU. Mở khoá giải mã hàng trăm tài khoản chỉ trong vài micro-giây và hỗ trợ tự động điền form (Autofill) an toàn chỉ bằng 1 chạm. Envelope encryption model utilizing memory-hard Argon2id key derivation and authenticated AES-256-GCM. Features 1-click safe DOM autofill injection.

Envelope KDF • Zero XSS

Chống lộ IP WebRTC & Farbling chống nhận diện vân tay WebRTC Leak Shield & Brave Farbling Emulation

Lọc bỏ địa chỉ IP mạng LAN nội bộ khỏi gói tin SDP của WebRTC, ngăn ngừa việc rò rỉ IP thật khi đang sử dụng VPN. Tự động bơm nhiễu siêu nhỏ vào Canvas và AudioContext để làm "mù" hoàn toàn các thư viện tracking fingerprint máy tính (như FingerprintJS). Purges local LAN IP candidates from SDP negotiations, sealing real IP leaks behind active VPN tunnels. Farbling injects imperceptible micro-noise into Canvas and AudioBuffer buffers to invalidate browser fingerprinting algorithms.
