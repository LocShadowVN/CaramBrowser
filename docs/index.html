for Linux workstations.

Tách biệt hoàn toàn giao diện Rust WASM với khung hiển thị WebKitGTK 4.1 gốc của Linux. Ăn chỉ ~118MB RAM lúc mở tab, tích hợp sẵn nhân chặn quảng cáo 300k rules của Brave, két mật khẩu Argon2id và bộ tải đa luồng xé băng thông như IDM. Decoupled Rust WebAssembly chrome with native WebKitGTK 4.1 subsurfaces. Sub-140MB idle footprint, 300,000+ Brave adblock rules, Argon2id vault, and IDM-grade chunked downloader.

Lõi lọc Brave adblock-rust (300k+ Rules) Brave adblock-rust Core (300k+ Rules)

Chạy trên luồng OS độc lập với thuật toán tra cứu Bloom Filter trie. Nạp sẵn EasyList, EasyPrivacy và Fanboy Annoyance. Can thiệp sâu từ prototype DOM (`HTMLScriptElement`, `WebSocket`, `sendBeacon`) để triệt hạ mã theo dõi trước khi phát sinh request và tự dẹp sạch banner Cookie/GDPR. Runs on an isolated OS worker thread hosting Brave Software's official engine. Precompiled with EasyList, EasyPrivacy, and Fanboy's Annoyance. Deep prototype hooks intercept trackers before network dispatches, automatically defusing cookie walls.

adblock-rust • Tokenized Trie

Két mật khẩu Vibird Vault (Argon2id + AES-256) Vibird Vault (Argon2id + AES-256-GCM)

Bảo mật theo mô hình Envelope Encryption: Dẫn xuất khoá chính bằng Argon2id (chống bẻ khoá GPU) đúng 1 lần khi mở két, sau đó giải mã hàng trăm tài khoản bằng AES-256-GCM trong vài micro-giây không gây đơ ứng dụng. Hỗ trợ tự động điền form (Autofill) an toàn bằng JSON chuẩn. Envelope encryption architecture: Memory-hard Argon2id key derivation executes once upon unlock, enabling microsecond batch decryption via AES-256-GCM without UI lockup. Features 1-click DOM autofill injection using strict JSON serialization.

Argon2id • Envelope Encryption

Bộ tải file đa luồng xé băng thông kiểu IDM IDM-Style Chunked Downloader

Tự động bắt Range byte, chia nhỏ file tải đồng thời từ 4 đến 16 luồng TCP song song. Tích hợp Download Sniffer tự chặn file nén, file cài đặt từ WebKit chuyển vào bộ tải, chống ghi đè Path Traversal và báo tốc độ theo thời gian thực. Forks payloads across 4 to 16 concurrent TCP threads via HTTP Range. Intercepts binary links via native WebKit download listeners, featuring path-traversal sanitization and live speed telemetry.

4–16 TCP Streams • Tokio Async

Ru ngủ tab thông minh (Triệt tiêu RAM Leak) Smart Tab Memory Eviction

Tiến trình giám sát nền tự động huỷ bỏ hoàn toàn Webview của những tab không tương tác quá 10 phút, trả lại 100% RAM và tài nguyên GPU cho máy tính chạy IDE hoặc Docker. Khi bạn nhấn chọn lại, tab tự động phục hồi đúng URL và trạng thái phiên duyệt. Background supervisor cleanly destroys the underlying native WebKit webview for tabs idle over 10 minutes, returning 100% of GPU context and DOM memory to the OS. Tabs seamlessly re-instantiate on demand when clicked.

True Native Eviction • Zero Leak

Chống lộ IP WebRTC & Brave Farbling WebRTC Leak Shield & Farbling

Lọc sạch địa chỉ IP mạng LAN nội bộ khỏi gói tin SDP của WebRTC, ngăn ngừa lộ IP thật khi đang sử dụng VPN. Tự động bơm nhiễu vi mô vào Canvas và AudioContext để làm mù hoàn toàn các thư viện tracking nhận diện vân tay máy tính (như FingerprintJS). Purges local LAN IP candidates from WebRTC SDP negotiations to prevent IP leaks behind VPNs. Injects imperceptible micro-noise into Canvas and AudioBuffer buffers to defeat fingerprinting trackers.

WebRTC Sealed • Anti-Fingerprint

Bóc mã theo dõi trên URL & Gỡ Google AMP Clean URLs & Direct De-AMP Engine

Tự động gọt sạch toàn bộ các tham số gián điệp khỏi link (`utm_*`, `fbclid`, `gclid`, `si`, `spm`, `mc_eid`...) trước khi bạn bấm truy cập. Nhận diện các liên kết chạy qua proxy Google AMP và chuyển thẳng người dùng về bài viết gốc của trang báo. Strips hyper-tracking tokens (`utm_*`, `fbclid`, `gclid`, `si`, `spm`, `mc_eid`) prior to navigation and transparently redirects Google AMP cached pages back to their canonical origin servers.
