System Architecture & Components

No packaged Node.js runtime, no V8 bloatware, no sponsored ecosystem tiles.

Network / Privacy

Caram Shield Core

Integrates the official Brave adblock engine on a dedicated, isolated OS thread using message-passing channels to guarantee non-blocking multi-threaded request filtering.

Cryptography

Argon2id + AES-256 Vault

Local password database. Uses memory-hard Argon2id key derivation with a 128-bit random salt and authenticated AES-256-GCM encryption with individual 96-bit nonces.

DNS Resolution

Encrypted DoH Subsystem

DNS queries are resolved over HTTPS (Cloudflare 1.1.1.1, Quad9, Google) via RFC 8484 with live millisecond latency benchmarking.

Frontend Engine

Leptos WebAssembly (WASM)

The browser chrome is compiled from Rust directly to WASM (CSR mode). Uses fine-grained reactivity signals for zero-virtual-DOM overhead.

Compatibility Layer

Caram WebBridge

Native WASM runtime layer that overrides User-Agents, mocks `window.chrome`, and polyfills Chromium client hints for Google Meet, Discord, and Slack.

Storage Layer

Thread-Safe SQLite

History, bookmarks, and user configurations are managed locally in SQLite through safe Rust mutex wrappers. Zero cloud sync sync-traps.
