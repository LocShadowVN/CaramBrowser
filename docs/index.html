Subsystem Architecture & Security Primitives

Zero bundled Node.js runtimes, no V8 bloatware, and no commercial crypto ecosystem upsells.

Shield Subsystem

adblock-rust Thread Core

Integrates Brave’s official adblock engine isolated onto a dedicated OS thread. Evaluates network requests via tokenized Bloom filter tries without blocking the UI rendering loop.

Anti-Tracking

Clean URLs & De-AMP

Automated parameter stripper cleans tracking queries (fbclid, gclid, utm_*) before network requests dispatch, automatically defusing Google AMP links to canonical origins.

Cryptography

Argon2id + AES-256 Vault

Local password storage protected by memory-hard Argon2id key derivation (128-bit random salt) and authenticated AES-256-GCM authenticated cipher blocks.

Anti-Fingerprinting

Brave Farbling Emulation

Injects micro-noise into Canvas toDataURL() and AudioContext buffer calculations to defeat hardware fingerprinting scripts without visual distortion.

Frontend Core

Leptos WebAssembly (WASM)

Browser chrome written in pure Rust compiled to WASM. Fine-grained reactivity signals drive tab management and omnibox controls with zero Virtual-DOM overhead.

Local Storage

Synchronous SQLite Engine

Bookmarks, history, and domain-specific shield overrides persist locally in a SQLite database with thread-safe mutex guards. Zero cloud tracking syncs.

Security Advisory & MVP Disclaimer

Experimental Project Status (AI-Engineered MVP)

Caram Browser is an experimental Minimum Viable Product (MVP) engineered with the assistance of advanced AI code generation models under human architecture steering. It was designed as an exploratory alternative to heavy Chromium builds on Linux desktop environments.

Because this software is in an active testing stage, it has not undergone an independent third-party cryptographic or security audit. You should not use it as your primary storage for high-value financial secrets or mission-critical workflows. We encourage developers and Linux security researchers to audit the repository, inspect the IPC boundaries, and submit issues on GitHub.

Target Audience Built for Linux enthusiasts, developers, and users seeking distraction-free, low-RAM desktop browsing without commercial telemetry.
Web Compatibility Scope Uses WebKitGTK 4.1. ~95% of the modern web functions out of the box, but DRM-encumbered media (Netflix, Spotify) is intentionally unsupported.
Open-Source & Free Distributed under the GNU General Public License v3.0 (GPL-3.0). You have complete freedom to inspect, fork, modify, and compile locally.
